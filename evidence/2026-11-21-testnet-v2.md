# Lathe V1 + V2 on X Layer testnet: deploy and smoke run

Date: 2026-11-21. Chain: X Layer testnet, chainId 1952, RPC `https://testrpc.xlayer.tech/terigon`. Code: commit `3fe6449`.

## What this proves, and what it does not

- **Proves:** on a real public network, the contract with memory circuits (V1) and receipts, rule lookup and input names (V2) does what the tests say. A memory order is checked and paid in one transaction, a wrong memory circuit is refused and its order stays open, a paid order has a receipt, anyone can run the paid circuit with a free read, and an unpaid order refuses to run. The V0 flows (pay, refuse, refund) still work.
- **Does not prove:** anything about real TapeOut circuits. TapeOut is not deployed on testnet (`2026-11-20-preflight.md`), so this run used `MockProcessor`, a mock factory and `MockUSDT`. Real circuits are covered by the mainnet-fork tests in `test/fork/` (14 tests), including the real latch for the `step` argument order and a real 3-input switch for input order (`2026-11-21-input-order-circuit.md`). No real circuit with both inputs and memory was found, so that combination runs on stand-ins only.

This contract replaces the V0 testnet contract `0xDF3B0240Ed38d267De67e9Ed3Bad66F0Db8747fD` (`2026-11-20-testnet-v0.md`), which stays on chain. The page (`web/config.js`) now points at the new address.

Deployer, buyer and builder in every order: the throwaway testnet wallet `0x5a15Dca0F83Ae5878fD20eF0f9444b59Dbef03a0`. Fee: 1%.

## Limits

- Mock circuits only (see above).
- Source not verified on OKLink (no API key yet).
- Batched `check` was not exercised on testnet; every circuit here is small enough to be checked inside `deliver`. It is covered by unit and fork tests.
- The page was pointed at this contract and its no-wallet read test passed against it; no order was created through the page on testnet with a real wallet.
