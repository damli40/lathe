# Lathe V0 on X Layer testnet: deploy and smoke run

Date: 2026-11-20. Chain: X Layer testnet, chainId 1952, RPC `https://testrpc.xlayer.tech/terigon`. Code: commit `666780b`.

## What this proves, and what it does not

- **Proves:** the order flow works on a real public network. An honest delivery is checked and paid in one transaction, a wrong delivery is refused and the order stays open, and the buyer gets the money back after the deadline.
- **Does not prove:** anything about real TapeOut circuits. TapeOut is not deployed on testnet (`evidence/2026-11-20-preflight.md`), so this run used `MockProcessor`, a mock factory and `MockUSDT`. The real-circuit proof is the mainnet-fork tests (`test/fork/`, `evidence/2026-11-20-eval-gas-budget.md`).

Deployer and builder in every order: a throwaway testnet wallet `0x5a15Dca0F83Ae5878fD20eF0f9444b59Dbef03a0`, funded with 0.2 testnet OKB from the X Layer faucet. Total spent: about 0.0003 testnet OKB.

## Limits

- Mock circuits only (see above). The refund-before-deadline revert was simulated by the smoke script, not sent.
- Source not verified on OKLink (no API key yet).
- Batched `check` (for circuits too big to check inside `deliver`) was not exercised on testnet; it is covered by unit and fork tests.
